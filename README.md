# Семейная касса

Учёт трат и доходов для себя и всей семьи: личные и общие счета, кошельки, переводы, цели, регулярные платежи, история и статистика. Работает в браузере и устанавливается на телефон как приложение (PWA).

## Как устроено

- **Сайт** — статические файлы в этом репозитории, публикуются через GitHub Pages. Сборка не нужна.
- **Данные и вход** — [Supabase](https://supabase.com): база Postgres, вход по почте, живые обновления.
- **Доступ** — правила в базе (Row Level Security): личные данные видит только владелец, общий счёт — только его участники.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка, экран входа, подключение скриптов |
| `app.css` | оформление, светлая и тёмная темы |
| `js/config.js` | адрес проекта Supabase и публичный ключ |
| `js/backend.js` | работа с Supabase: документы, живые обновления, вход, имена людей |
| `js/app.js` | интерфейс и логика приложения |
| `sw.js`, `manifest.webmanifest`, `icons/` | установка на телефон и работа оболочки без сети |
| `supabase/schema.sql` | таблицы, правила доступа и функции базы |

## Первая настройка

1. **Supabase → SQL Editor → New query**: вставьте содержимое `supabase/schema.sql` и нажмите **Run**.
2. **Supabase → Authentication → URL Configuration**: в **Site URL** укажите адрес сайта (например, `https://логин.github.io/semeynaya-kassa/`) и добавьте его же в **Redirect URLs**.
3. В `js/config.js` впишите **Project URL** и **anon / publishable key** из **Project Settings → API Keys**. Секретный ключ (service_role / secret) никуда не вставляйте.
4. **GitHub → Settings → Pages**: Source — *Deploy from a branch*, ветка `main`, папка `/ (root)`.

## Перенос данных

В приложении: **Настройки → Аккаунт и резервная копия → Восстановить из файла**. Файл резервной копии можно скачать там же кнопкой «Скачать копию».

## Ограничения

- Без интернета открывается оболочка приложения, но записи не сохраняются.
- Курсы валют для сводки по всем счетам задаются вручную.
